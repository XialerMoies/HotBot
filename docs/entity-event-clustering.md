# 主体识别与增量事件聚类验收

日期：2026-09-27。

## 本次实现

### 主体识别

- 修复 Python NER `{name, type}` 与 Java 读取 `text/word` 的字段错配；兼容旧字段。
- NER 与 Embedding 分别执行。向量返回空数组或异常，不再导致全部主体识别被跳过。
- `EventEntityResolver` 提供不依赖外部服务的科技主体别名与版本化产品识别，补充模型结果。包括英伟达/NVIDIA、微软/Microsoft、人物姓名、GPT 型号、Blackwell B200、Claude Code 等。
- 所有实体都须在标题、摘要或正文摘录中出现。不会因为认识一个产品，就自动添加原文未提及的所属公司。
- 已知公司归为 `COMPANY`；通用 `ORG` 保留为机构，只有明确公司名称证据时才归为公司。保留人物、产品、技术类型，过滤无依据的模型输出。
- 标题中的主体优先，随后按主体类型排序；避免摘要中偶然提到的公司压过标题人物。每个事件只保留一个主要主体。
- 首页与工作台用中文显示类型；规则权重不再直接展示成准确率百分比。

当前降级识别是有限别名表、型号规则和原文匹配，不是通用完整 NER。未覆盖的新公司、人物仍需要模型输出或人工补充。匹配到实体也不代表已通过人工事实审核。

### 多源入库与聚类

- 去掉按标题前六字近似去重的逻辑。采集只去重同来源同原文地址的重复投递，保留不同来源的报道。
- RSS 文章 ID 使用来源和原文 URL 的稳定 UUID，避免中文来源被清空后发生 ID 碰撞。
- 兼容旧 ID：相同来源、相同 URL 已存在时复用已入库文章，不新增孤立记录。入库复制对象，防止调用方修改已保存的 ID 或特征。
- 生产事件匹配使用已存原始报道进行逐篇比较。主体相同是条件之一，不能单独决定归并。
- 标题完全一致、相同 CVE 编号、同版本产品发布到交付、带事件内容锚点的主体/动作/文本匹配均可提供归并依据。
- 向量可用时辅助判断；向量不可用时使用较保守的实体、型号、动作和标题信号。
- 不同公司、不同产品、不同事故编号、不同事件动作冲突时拒绝合并。即使向量完全一致，也不能把 GPT-5 与 GPT-6、发布与诉讼、发布与宕机自动合并。
- 14 天窗口是硬边界，且以事件首篇报道约束，避免连续追加无限延长事件。无法解析发布时间时不自动并入其他事件。
- 同一事件追加保留所有来源文章、原文地址和时间节点，状态变为持续更新；重复抓取不重复追加。
- ISO、RSS RFC 1123、日期格式复用 `NewsTimeUtils` 解析。乱序报道按时间排序，并且只有最早节点标记首次报道。
- 响应 `signals` 返回实际匹配依据。分数不足的记录保持独立；当前 `candidate-review` 表示候选状态原因，尚无人工合并管理工作流。

产品型号+发布动作仍是启发式规则，可能将同型号短期内的两次独立发布误判为同一事件；标题含糊、跨语种叙述差异大或长周期事件也可能漏合并。需要后续标注集与阈值实验，不能将回归用例通过视为聚类准确率。

### 存量补算和界面

- 启动时给现有文章补算主体、关键词与可解析发布时间，再更新事件主体及时间线。
- 保留公开事件 ID 和文章 ID；不会为了展示多源效果强行重分现有事件。
- 发生补算变化时，先将原存档备份到 `bot-server/storage/quarantine/features-*/events.backup.json`，再原子写入。
- 工作台加载证据后显示实际来源数量和时间节点对应来源；游客的证据入口仍触发登录。
- 本次存量 19 个事件中，17 个具有类型化主体，2 个保留主体待确认。这是覆盖数量，不是准确率；部分事件只有技术主体，并非都识别到了公司。
- 存量没有被伪造为多源事件。3 来源合并场景使用临时测试数据完成，未写入生产存储。

## 已验证场景

| 场景 | 结果 |
| --- | --- |
| OpenAI、Sam Altman、GPT-5 同文出现 | 分别为公司、人物、产品 |
| 原文只有 Claude 与 Excalidraw | 产品主体，不虚构所属公司 |
| 联合国被模型标记 ORG | 保持机构，未当作公司 |
| 英伟达 B200 中文发布 / NVIDIA B200 英文发布 | 合为同一事件 |
| 重启后追加 B200 交付 | 原 ID 下变为 3 篇报道、3 个来源、3 个时间节点 |
| 相同内容再次抓取 | 不重复追加 |
| 同来源同 URL 变更抓取 ID | 不增加事件或孤立文章 |
| GPT-5 / GPT-6 发布，即使向量相同 | 保持不同事件 |
| GPT-5 发布 / 版权诉讼 / 服务中断 | 保持不同事件 |
| 苹果触觉专利诉讼 / 判决 / 上诉 | 合并并追加 |
| 苹果触觉专利案 / Apple Pay 反垄断案 | 保持不同事件 |
| OpenAI / Google 的类似发布标题 | 不因共享 AI 词而合并 |
| 超过 14 天 / 时间不可解析 | 不自动并入现有事件 |
| 较早报道后到 | 时间线重排，首次报道标记正确 |
| 新主体补算后重启 | 保留事件 ID 与文章引用 |
