# 前端收尾验收记录

日期：2026-09-27

## 本轮范围

统一工作台、设置、来源文章和登录弹窗的冷灰 / 炭黑 / 安全橙视觉。继续使用现有 Vue、Reka UI、Lucide 与 Button 组件。未修改采集、聚类、实体识别、模型或后端权限逻辑。

## 已实施

- 统一标题字体与字号、标签栏、控件、面板、证据区和表单样式；去掉工作台与设置的装饰性英文编号及重复说明。
- 工作台证据改为主动点击后加载。游客入口打开登录框；退出或切换账户后清除已加载证据和问答。
- 工作台分页统一为 14 项；换页选择当前页事件，无筛选结果不残留旧详情。
- 工作台和设置标签由路由决定，支持浏览器前进 / 返回。
- 登录弹窗增加明确关闭按钮；提交期间禁用切换与重复提交；关闭后迟到响应不能保存登录信息。
- 认证请求失效时清理对应会话并提示登录；旧令牌的迟到错误不会清除新令牌。
- 跨标签页令牌变化重新加载工作区；个人操作增加账户切换后的过期响应保护。
- 增加 1500 / 1100 / 760 px 布局规则、可滚动标签栏、移动 Dock 底部留白、长文本换行和弹窗高度限制。

### 页面、尺寸与缩放

- 首页；工作台的态势概览、事件追踪、来源文章、证据问答；设置的个人配置与任务监控。
- 游客视图：1920×1080、1440×900、1024×768、768×1024、390×844。
- 登录视图：1920、768、390 宽度的关注、订阅、提醒、摘要、问答表单。
- 通过仅用于隔离测试浏览器的本地扩展调用 Chrome 原生标签缩放，验证 80%、125%、150%；不是 CSS zoom 或截图缩放。
- 检查页面横向溢出、控件边界、Dock 四个入口的点击命中、选中标签颜色；检查桌面、手机、150% 缩放、任务表格和登录弹窗截图。
- 手机管理标签采用横向滚动，表格在容器内滚动；响应式会换列，不要求不同宽度保持相同列数。

### 真实账户与操作

使用独立 qa_ 前缀测试账户，未读取或修改真实用户私有数据。

- 注册创建工作区、错误密码反馈、登录、退出、重新登录。
- 添加关注、重复关注提示、首页“我的关注”过滤。
- 添加订阅、暂停、恢复，刷新后记录保留。
- 生成每日摘要、产生匹配提醒、标记已读。
- 取消删除、确认删除测试账户自己的关注与订阅。
- 真实事件证据请求、跳转问答、提交并展示检索降级回答。
- 注入 503 验证订阅、列表、证据、问答的失败提示与重试；注入 invalid token 验证会话清理及登录提示。故障注入仅作用于隔离测试浏览器，不修改服务。

### 本轮发现并修复的问题

1. 工作台选中标签被更晚的 CSS 覆盖成深色文字，导致暗底不可读；修正优先级。
2. 移动 Dock 的 nav 被旧 sidebar 规则覆盖成纵列，部分入口不可见；显式恢复横向排列并检查四个按钮命中。
3. 直达非第一页事件时被目录首项覆盖；先定位目标所在页，再执行无效目标回退。新增组件回归测试并用真实链接、证据请求复测。

### 可复现入口与证据

- `npm --prefix frontend test -- --reporter=dot`
- `npm --prefix frontend run build`
- `python frontend/e2e/acceptance.py`
- `python frontend/e2e/extended_acceptance.py`

浏览器脚本需要 Python Playwright 和本机 Chromium，使用正在运行的 5173 / 8180 服务。第一份脚本会创建测试账户并写入本地 logs；第二份复用该账户。两份脚本任一检查失败均以非零退出码结束。

截图、逐项 JSON、隔离测试浏览器配置和临时测试凭据位于被 Git 忽略的 `logs/frontend-acceptance/`，不得提交测试凭据。测试账户及其测试摘要 / 提醒保留在本地后台；测试关注、订阅已删除。

## 验收结论与边界

本轮已完成约定的前端主要路径、布局、浏览器缩放和异常恢复验收，不代表跨所有浏览器的兼容性认证。测试使用本机 Chromium，没有真实移动设备 / Safari / Firefox 实测。

问答本次实际返回检索降级结果：验证了接口、降级标识和证据展示，不验证模型事实准确性。部分现有事件来自历史测试数据或无关新闻，原文缺失时显示“未提供原文链接”。采集质量、主体识别、聚类质量与实验指标仍属下一阶段。

前端登录入口控制不能替代后端接口授权。工作区刷新及重新登录的数据保留已验收；未进行后台重启恢复或生产级安全验收。
